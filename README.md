## The system at a glance

**Colorway** — Paper `#ECE7DA` · Ink `#1C1712` · Espresso `#2A211A` · Signal `#C93A1E`
**Type** — Bodoni Moda (display) + Space Mono (system), both Open Font License
**Mark** — a fine horizon arc with a point of first light at its apex

The point has two states: a **crisp solid point** on light grounds, and a
**luminous halo** on dark grounds. Never use the glow on a light surface.
